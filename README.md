# Metasploitable2-Writeups

Tady si budu psát postup, jak daleko jsem v Metasploitable 2.0 a jak mi to jde.
Budou to moje studijní zápisky k učení a procvičování.

## Co tu najdeš
- průběžné poznámky k postupu
- zápisky k jednotlivým zranitelnostem
- jednoduché ukázky vlastních exploitů v C

## Struktura
- `notes/vulnerabilities/` – zápisky o každé využité zranitelnosti, proč k ní došlo a co jsem si o ní zjistil
- `exploits-c/` – místo pro vlastní jednoduché C zdrojáky (simple exploity)
